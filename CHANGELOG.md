# История изменений (Changelog)

Все заметные изменения в проекте **Geo Routing Server** документируются в этом файле.  
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект придерживается [Семантического версионирования (SemVer)](https://semver.org/lang/ru/).

---

## [1.5.0] - 2026-09-28

### Исправлено
* **Скрипт управления (`install.sh`):**
  * В глобальную палитру цветов добавлены недостающие константы `C_MAGENTA` и `C_BLUE` (предотвращает сбой `unbound variable` в Bash при выборе пресетов).

### Добавлено
* **Мульти-пресетная одновременная раздача (`ROUTING_SOURCE_PRESET`):**
  * Поддержка перечисления нескольких источников через запятую (например, `hydraponique,geogaga` или `geogaga,vahellame`).
  * Параллельная генерация геобаз и правил для нескольких апстримов в рамках одного токена без конфликтов.
* **Изолированные пути вторичных пресетов:**
  * Основной пресет сохраняет 100% обратную совместимость и раздаётся по корневым путям (`/<TOKEN>/HAPP/`, `/<TOKEN>/INCY/`).
  * Вторичные пресеты изолируются в подкаталогах верхнего регистра (`/<TOKEN>/<PRESET>/HAPP/`, `/<TOKEN>/<PRESET>/INCY/`).
  * Идеально для безопасного A/B тестирования новых источников (например, GeoGaga) без отключения текущих абонентов.
* **Расширенная интеграция с Remnawave:**
  * Поддержка правил вторичных пресетов (`GEOGAGA/HAPP.JSON`, `VAHELLAME/WHITELIST.JSON`).
  * Функция нормализации `normalize_squad_rule` сохраняет префикс каталога и корректно распознаёт полные URL.
  * Автоматический патчинг заголовка `x-happ-routing` в Remnawave API с диплинком соответствующего пресета.
* **Обновления в TUI и установщике (`install.sh`):**
  * Пункт 5 меню хоста позволяет в один клик включить `⚡ Мульти-пресет: hydraponique + geogaga`.
  * Мастер первичной установки (шаг 5/6) предлагает мульти-пресет из коробки.
  * Интерактивная привязка правил для сквадов группирует правила на `[Основной]` и `[Вторичный]`.
  * Расширен Nginx regex fallback для проксирования путей вторичных пресетов.
* **Тесты:** добавлены сквозные тесты одновременной работы процессоров, разрешения диплинков и синхронизации сквадов с Remnawave API (228 тестов).

## [1.4.0] - 2026-09-27

### Добавлено
* **Встроенный Python CLI (`app/cli.py`):**
  * CLI-приложение на стандартной библиотеке Python без внешних зависимостей.
  * Команды `status`, `sync`, `proxy`, `squads`, интерактивное TUI-меню.
* **Единый источник правды (Single Source of Truth):**
  * Генерация артефактов `.sync-status.json` и `.sync-summary.txt` в директории токена при синхронизации.
  * Статус и ссылки отображают 100% реальные сгенерированные файлы без риска 404-ошибок.
* **Структурированное хранение сквадов (`squads.json`):**
  * Перенос привязок из `.env` в атомарный JSON-файл `squads.json` с валидацией схем и автомиграцией старых настроек.

### Исправлено
* **Устранение дефектов бэкенда (#14–#19):**
  * 4-этапный fallback для geo-баз (явный URL -> `DEFAULT.JSON` -> URL пресета -> официальные релизы GitHub) с кэшированием в памяти.
  * Fallback правил по умолчанию при пустом результате discovery.
  * Очистка устаревших файлов для всех пресетов по актуальному реестру сессии.
  * Нормализация регистра диплинков (`.upper()`).
  * Корректная обработка `HTTP 204 No Content` от API Remnawave.
  * Удаление локальных баз при внешнем `PUBLIC_GEO_BASE_URL` или отключенной раздаче.
* **Безопасность:**
  * Защита логов Nginx: маскирование токена и отключение access-лога для статики геобаз.
  * Защита системных путей в `install.sh`: блокировка случайного удаления корневых каталогов при uninstall.

## [1.3.3] - 2026-09-22

### Безопасность
* **Защита от спуфинга заголовков в Nginx:** токен-независимые пути `/HAPP/` и `/INCY/` проверяют только реальный TCP-адрес (`$remote_addr`). Прокси-заголовки `X-Forwarded-For` запрещены на этих путях.
* **Контейнер по умолчанию:** `cap_drop: ALL` с точечным добавлением минимально необходимых capabilities, `no-new-privileges`, очистка отладочных пакетов.

### Исправлено
* **Надёжная запись настроек в `install.sh`:** вывод меню переведён в `stderr` (`>&2`), операции записи `.env` переведены на атомарную схему `mktemp` + `mv`.
* **Умные повторы в загрузчике:** прерывание ретраев при фатальных HTTP 400/403/404, учёт `Retry-After` при HTTP 429.
* **Единый контракт имён:** строгий верхний регистр `<БАЗА>.DEEPLINK`, валидация диплинков Incy.

## [1.3.2] - 2026-09-16

### Исправлено
* **Внешние Geo URL в Incy:** `PUBLIC_GEO_BASE_URL` гарантированно заменяет upstream-ссылки в `INCY.JSON` независимо от флагов локальной раздачи.
* **Автонормализация схем:** отсутствие префикса `https://` больше не сбрасывает адрес.
* **Отображение в баннере:** `geoserver status` показывает внешние базы даже при выключенной локальной раздаче.

## [1.3.0] - 2026-09-06

### Добавлено
* **Пресет GeoGaga (Client Flavor):** сбалансированный сплит-туннель для РФ с лёгкими и актуальными базами.
